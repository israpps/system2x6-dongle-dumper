# Arcade Security Dongle update binder

this program allows to use a retail PS2 to load an arcade PS2 KELF and bind it to the an security dongle (`COH-H10020`) connected to the console. saving you the hassle of buying a PS3 CECHZM1 or soldering, etc...

if the operation suceeds, the bound KELF is written to the card root as `boot.bin`, ready to be used.
